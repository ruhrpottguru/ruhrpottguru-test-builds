RuhrpottGuru Places Backend 1.10.36 – Eventbilder: Browser-Transport
=================================================================

Ziel
----
Keine neue Bildzuordnung. Die in rg_event_media bereits per ET4/global_id verifizierten
Original-Bild-URLs bleiben unverändert gespeichert. Nur der Browser-Transport wird
vereinheitlicht: Besucher erhalten eine HTTPS-URL auf RuhrpottGuru (admin-ajax.php),
die ausschließlich eine vorhandene aktive event_media-ID akzeptiert.

Datenweg
---------
ET4 global_id -> rg_event_media (bestehend) -> Event-REST -> RuhrpottGuru Bild-Proxy
-> unveränderte Bildbytes -> aktuelles Theme normalizeEvent() -> Media <img>.

Sicherheit / Verhalten
----------------------
- Kein URL-Parameter für fremde Bildquellen; Browser übergibt nur media_id.
- Proxy löst media_id serverseitig gegen wp_rg_event_media auf.
- Nur aktive Bild-Medienzeilen mit zulässigem Health-Status.
- Download über wp_safe_remote_get (SSRF-sicherer WordPress-Transport).
- Erlaubt JPEG, PNG, WebP, GIF, AVIF; HTML/PDF/SVG/sonstige Inhalte werden nicht ausgeliefert.
- Byte-/MIME-Prüfung vor Ausgabe; widersprüchliche MIME-Angaben werden abgelehnt.
- Unveränderte Originalbytes werden lokal unter uploads/rpg-event-image-cache gecacht.
- ETag + Browsercache; Upstream wird nach lokalem Cache-Hit nicht erneut benötigt.
- Kein Eingriff in ET4/global_id-Zuordnung, Source Ownership oder Opening-Hours-Audit.

-----------------------
