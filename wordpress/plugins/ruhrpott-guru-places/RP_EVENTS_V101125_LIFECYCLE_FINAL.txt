POLICY
- A source hit resets missing evidence and immediately reactivates source-missing rows.
- A missing event is counted ONLY after a fully successful source wave.
- First complete-wave miss: source_status=missing, event remains public/active.
- Same run token cannot increment missing_count twice.
- Public deactivation requires BOTH:
  1) at least two distinct completed source waves with a miss, and
  2) at least 24 hours since missing_since.
- Deactivation uses status=inactive; it is not a physical delete.
- Explicit source cancellations are status=cancelled immediately, including source objects that emit no occurrence.
- Failed/incomplete ET4 pages and supplemental waves with failed cities do not reconcile Missing state.
- A complete destination.one 53-city wave no longer hard-deletes missing events; it uses the same lifecycle.
- Existing natural expiry remains: ended active events -> expired; physical cleanup remains 10 days after natural end.

CANCELLATION INPUTS
- Explicit boolean flags including cancelled/canceled/abgesagt variants.
- Explicit scalar status fields including schema.org EventCancelled/EventCanceled and common cancelled/abgesagt values.
- Cancellation marker at the beginning of an event title.
- Generic description/body text is intentionally NOT used for cancellation, avoiding false positives such as cancellation-policy wording.
