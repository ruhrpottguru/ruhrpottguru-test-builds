VERIFIED ROOT CAUSES FROM 53-CITY AUDIT
1. The diagnostic SQL had ORDER BY id ASC LIMIT 5000. A displayed total of exactly 5,000 therefore could not prove a complete 53-city audit.
2. Nameless high-specificity table-tennis OSM objects receive the derived display name "Tischtennisanlage". The V2 admission rule then matched that synthetic name and promoted the same object to REIN. This contradicted the V2 spec, which starts table tennis at BEDINGT unless real public/leisure evidence upgrades it.
3. Website/opening-hours metadata are boosters, not visitor-access proof. Shooting/model-flying/golf must not become REIN from those fields alone.
