ROOT CAUSES VERIFIED IN v1.10.69 CODE
1. opening_audit_remote_search() treated public search-engine HTML discovery as a completion gate whenever no readable official site was available.
   Result: if both DuckDuckGo and Bing blocked/timed out server-side, the case stayed research-incomplete even when the identity-bound source chain had otherwise been exhausted.
2. opening_audit_site_hours() set the entire official-site path to incomplete when ANY of the selected auxiliary subpages failed.
   The candidate set included weak links such as Kontakt, Info, Service and Besuch.
   Result: a readable official root page could still become research-incomplete because a non-critical helper page returned 403/404/timeout.
3. The stored diagnosis collapsed these structurally different conditions into one generic text:
   'Mindestens ein Quellenpfad war technisch nicht vollständig prüfbar.'
   Therefore the old admin list could not distinguish the real failure mode.
