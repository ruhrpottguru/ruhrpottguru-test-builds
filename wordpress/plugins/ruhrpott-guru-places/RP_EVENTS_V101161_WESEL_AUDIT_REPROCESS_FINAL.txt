1.10.161 changes
1) Occurrence identity / dedupe
- Same-day + close-time high-confidence duplicates remain existing/merge candidates.
- Real interval overlap remains an existing duplicate signal.
- Neighbour-date title similarity remains a conservative conflict signal for unrelated/cross-source data.
- Exception: if a nearby row is already owned by or carries an attached WeselMarketing source_uid different from the incoming Wesel source_uid, it is a distinct official occurrence and is not blocked as a conflict.
- This handles both Wesel-owned rows and ET4 rows to which the first Wesel occurrence was attached as provenance.

2) Geo resolution
- Exact city + postcode + street + house number in active Places is accepted as identity-safe geo even without a venue-name match.
- If Places lacks the address, a canonical event with the exact same address, usable geo and address_status complete/verified/manual may be reused.
- Street/postcode-only fallback still needs strong venue evidence; a different house number without venue identity remains blocked.
- No city-centre coordinate fallback is introduced.

3) Central reprocessing
- New job: wesel-audit-reprocess-v101161.
- Registered through the existing versioned reprocessing framework (no one-off worker architecture).
- Autostarts once because of a new immutable fingerprint.
- Resumable monotonic candidate-ID cursor; batch size 3.
- Uses only stored raw_payload candidate data for event fields; no calendar/detail refetch.
- Shares the external-event conflict lane because approved images may be materialized for newly imported events.
- Existing event-symbolic reprocess keeps its cursor and resumes after this higher-priority job.

4) Admin audit visibility
- RP Redaktion -> Events shows both the historic full-sync audit counter and the current number still held back.
- Expandable "Nur Audit anzeigen" table shows up to 100 current rows with event, time, venue/address, concrete audit reason and source-page link.
- Reprocess status/progress is shown directly in the Wesel coverage panel.
