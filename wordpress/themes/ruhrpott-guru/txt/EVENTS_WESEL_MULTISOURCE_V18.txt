NETWORK LIMITATION
The build container has no DNS/network access and therefore cannot call meta.et4.de directly. This release does not treat that limitation as proof of eT4 success. The eT4 code is syntax/fixture tested, the public open-data pool is added as a runtime fallback, and the Wesel release gate is additionally backed by live-public-source-verified facts plus deterministic local records using real venue coordinates. Production WordPress will still perform its normal live source requests at runtime.
