# RuhrpottGuru – Entwicklungsbestand

Zentraler Einstieg für Theme, Places-Backend und technische Nachweise. Pflege und Auswahl der Dateien liegen beim verantwortlichen Systemarchitekten; Jürgen muss Release-Dateien nicht zusätzlich als Projektquelle hochladen.

## Verzeichnisstruktur

| Pfad | Zweck |
|---|---|
| `wordpress/themes/ruhrpott-guru/` | Vollständiger Theme-Archivstand einschließlich Build-Dateien, Assets und vorhandener Tests |
| `wordpress/plugins/ruhrpott-guru-places/` | Vollständiger Places-Backend-Archivstand |
| `docs/source-inventory.json` | Herkunft, Archivprüfsummen und Hash jedes übernommenen Quellfiles |
| `docs/current-state.md` | Entwicklungsstand, Nachweisqualität und noch fehlende Live-Bestandteile |
| `docs/storage-policy.md` | Ablage-, Versions- und Release-Regeln |
| `AGENTS.md` | Verpflichtender Einstieg für die nächste Entwicklungsarbeit |

Die bestehenden August-Test-Releases bleiben historische Testversionen. Dieser Import ist eine Archivübernahme und keine neue Produktionsversion oder Installationsfreigabe.

Vor jeder Arbeit `AGENTS.md`, `docs/current-state.md` und die aktuellen verbindlichen Projektunterlagen lesen. Ein Git-Stand beweist keinen installierten WordPress-Stand. Der Inhalt dieses Repositories ist öffentlich; Zugangsdaten, Datenbankexporte, private Kommunikation und personenbezogene Diagnoseprotokolle gehören nicht hinein.
